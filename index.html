Owner-operated utility

Private research backup and recovery

Personal Research Backup Access is a small, noncommercial utility for safeguarding research archives and related project files. The owner uses authorized Google Drive connections, encrypted or access-controlled cloud storage, and integrity checks to support recoverable backups.

Private use • No public file sharing

How it works

The owner authorizes access to their own Google Drive account. Separate connections may read selected files for backup and recovery, or write backup files created by the utility when explicitly configured to do so.

Selected files may be copied to private cloud object storage, including DigitalOcean Spaces, with file sizes, checksums and restore checks used to verify the copies. The website itself does not access Google Drive, request sign-in or host the research files.

Access and safeguards

This utility is intended for the account owner, not offered as a public storage product. Google Drive permissions are requested through Google's standard OAuth consent flow. Read-only connections cannot modify Drive files. Backup writing connections are configured separately.

Research archives, OAuth tokens, private keys and backup manifests are not published on this site. The public pages provide information about the utility and its data practices only.
